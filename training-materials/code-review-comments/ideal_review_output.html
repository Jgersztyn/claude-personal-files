Evidence behind the review
  • Unfitted CSS on a real Stories build (headless Chrome, probe story with 5 images plus a chart, a failed tile and an empty full-row tile):
    • The grid scrolls: scroll height 1536 against 404 visible.
    • Each image fills its tile width at its own 1.16:1 ratio.
    • The short last row keeps its neighbours' width.
    • Each full-row tile is exactly clamp(18rem, 40vh, 32rem) (288px at that size).
  • Guard mutations:
    • Deleting the _askedFor guard fails only Unfit_SlotStillMissing_....
    • Moving the guard below the rebuild await fails only Unfit_WhileThePanelsAreStillBuilding_....
    • Deleting the unfitted early return in Measure fails nothing; it only skips a re-render that changes nothing.
  • Change detection: before this branch, Blazor already skipped re-sets where every parameter kept its value. A DynamicComponent probe showed this, so the guard only ever short-circuits the Fit to Screen toggle. It removes no reachable retry.
  • Charts-only view on a real Stories build:
    • One chart: 744px fitted, 288px unfitted.
    • Three charts unfitted: they scroll (876 > 744) and lose 10px of width to the scrollbar.
